Hugo 是用 Go 語言編寫的開源靜態網站產生器，遵循 [Apache Licence 2.0](https://github.com/gohugoio/hugo/blob/master/LICENSE) 授權。 Hugo 支援 TOML、YAML 和 JSON 資料檔案類型，以及 Markdown 和 HTML 內容文件，並使用短程式碼來添加豐富的內容。其他顯著功能包括分類法、多語言模式、影像處理、自訂輸出格式、HTML/CSS/JS 壓縮以及對 Sass SCSS 工作流程的支援。

Hugo 使用了多種開源項目，包括：

* https://github.com/yuin/goldmark
* https://github.com/alecthomas/chroma
* https://github.com/muesli/smartcrop
* https://github.com/spf13/cobra
* https://github.com/spf13/viper

Hugo 非常適合部落格、企業網站、創意作品集、線上雜誌、單頁應用程序，甚至是擁有數千頁的網站。

Hugo 適合那些希望手動編寫自己的網站，而不必擔心設定複雜的執行環境、依賴項和資料庫的人。

使用 Hugo 建置的網站速度極快、安全性高，並且可以部署在任何地方，包括 AWS、GitHub Pages、Heroku、Netlify 以及任何其他託管提供者。

在 [GitHub](https://github.com/gohugoio) 上了解更多並參與貢獻。
